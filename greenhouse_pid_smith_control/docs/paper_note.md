# 课程论文代码说明

本文代码对应论文第 5 节“仿真方案与结果分析”。

## 可写入论文的描述

为验证串级 PID 与 Smith 预估补偿控制方案的有效性，本文采用 MATLAB 编写离散仿真程序，对温室温度对象进行数值模拟。温室主对象采用一阶惯性加纯滞后模型，采样周期为 1 s，仿真时长为 3600 s。仿真中设置初始温度为 20 ℃，目标温度为 25 ℃，并在 2400 s 加入外界温度扰动，用于比较不同控制方案的跟踪性能和抗扰动能力。

## 图表对应关系

- `temperature_response_comparison.png`：不同控制方案温度响应对比图；
- `control_output_comparison.png`：不同控制方案控制量输出对比图；
- `performance_metrics.csv`：三种控制方案性能指标表。
